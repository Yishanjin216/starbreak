# 碎星 STARBREAK —— 分享版

> **怎么玩**：双击 `碎星-STARBREAK.html`，用浏览器打开就能玩。
> **不需要联网、不需要安装任何东西、只有一个文件。**

---

## 发给别人时怎么说

直接把 `碎星-STARBREAK.html` 这**一个文件**发过去（微信 / QQ / 邮件都行），
对方双击打开就玩。可以照抄下面这段话：

> 一个单文件小游戏，双击就能玩，不用装东西。
> WASD 移动，**按住空格或鼠标左键蓄力，松开冲出去撞碎敌人**。
> 鼠标指哪儿冲哪儿。蓄力到**金色区间**再松手是「完美冲刺」，能破重甲。

## 操作

| 操作 | 按键 |
|---|---|
| 移动 | `W A S D` 或 `↑ ← ↓ →` |
| **蓄力 / 冲刺** | **按住 `空格` 或鼠标左键**，松开冲出去 |
| 瞄准 | **鼠标指哪冲哪**（冲刺方向始终跟随光标） |
| 星爆（清屏大招） | `E` 或鼠标右键（需充能满） |
| 暂停 / 静音 / 全屏 | `P` · `M` · `F` |

## 三个要点

1. **蓄力分好坏**：按住不动会看到一圈蓄力环。
   进到**金色区间**（约 62%~83%）松手是「完美冲刺」——能破甲、能穿透；
   蓄过头反而变回普通冲刺。**贪心蓄满会吃亏。**
2. **回声**：你每次冲刺，都会在 0.34 秒后**被重放一遍**——
   身后永远跟着一个延迟的你，能替你补刀、也能帮你续连击。
   副标题「你身后的那个自己，也会撞上去」说的就是这个。
3. **带甲的要打准**：橙色重壳有两层甲，只有完美冲刺能破；
   撞不动会被弹开、还会断连击。

## 它为什么只有一个文件

游戏里的**每一张图、每一个音效，都是代码现画 / 现算出来的**——
没有任何图片文件、没有音频文件、没有字体文件，也没有一行网络请求。

- 画面：Canvas 逐帧绘制（敌人形状是多边形、辉光是运行时生成的渐变）
- 声音：Web Audio 现场合成（振荡器 + 程序生成的白噪声）
- 字体：用系统自带的（`Segoe UI` / `Microsoft YaHei` / `Consolas`）

所以它天然离线、天然好传——**断网也能玩，拷到 U 盘也能玩**。

---

## 兼容性

- 用 **Chrome / Edge / Firefox** 等现代浏览器双击打开即可。
- 手机浏览器理论上能开，但**操作需要键盘和鼠标**，实际请在电脑上玩。
- 最高分会存在浏览器本地（`localStorage`）；如果浏览器禁用了本地存储，
  游戏照常玩，只是不记最高分。
